# Privacy Policy

## 1. Introduction

This Privacy Policy defines the handling of user information in the service provided by the Service Provider (hereinafter referred to as "the Service").

## 2. Access to Storage

The application accesses the device’s storage to import photos into the app.
The application also accesses the device’s storage to save photos created within the app.
